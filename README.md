# Crypto Portfolio Analytics API

[![CI](https://github.com/JoaoAnisio/crypto-portfolio-analytics/actions/workflows/ci.yml/badge.svg)](https://github.com/JoaoAnisio/crypto-portfolio-analytics/actions/workflows/ci.yml)

API REST para acompanhamento de portfólio de criptoativos, com cálculo de custo
médio ponderado, resultado realizado e não realizado, e histórico diário automatizado.

**Stack:** Java 21 · Spring Boot 4 · PostgreSQL · Redis · Flyway · Docker · Testcontainers
